# Make-It — reproduction evidence

Screenshots, short GIFs and the scripted steps used to reproduce issues reported in
[c0d3-dump/make-it](https://github.com/c0d3-dump/make-it).

Each folder holds the evidence for one issue (the folder name matches the issue's evidence link)
and, where applicable, `repro.json` — the exact steps the running app was driven with. Every issue
was reproduced at least twice from a fresh launch; most three or more times.

Build under test: `make-it` 0.2.1, commit `3d556b9`, macOS 27.2.1 (Apple M4), release build.
